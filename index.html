内置工具

list_tables 工具可查询所有表的结构、约束、索引、触发器等详细信息。
sqlite_execute 工具可执行任意 SQLite SQL 语句，参数支持 SQL 绑定变量。
mongo_execute 工具可执行任意 MongoDB 操作（find、aggregate、insert、update、delete 等），参数需指定 collection 及操作类型。
